# Gomi Sort (Waste Sort Game)

Gomi Waste Sort: Brand New Game
Catch falling Gomi (rubbish) and drop it in the right bin, Japanese-style. How long can you keep your hearts?

Gomi Sort is a fast, relaxing game where you sort household waste the Japanese way. 
Items fall one at a time, and you steer each one into the right bin before it lands. 
The game gets faster every level, so you'll need quick reactions. 
Peel the cap and label off PET bottles for bonus points, and win back a heart for every 3 correct sorts. 
It's playable on desktop and mobile.
